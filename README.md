Geom.js
========================================================================

A bunch of geometry-related JavaScript classes optimised for clarity for
the author, rather than performance. The reasons are unsophisticated: my
grasp of mathematics is atrocious, and the only thing that helps me grok
trigonometry is seeing it visualised in real-time.

Like [Alhadis/Utils](https://github.com/Alhadis/Utils), this project has
no real name; `Geom.js` was brashly chosen as a placeholder. Since then,
other cuspy classes have crept into this repository, if only because the
brutally-semantic coding style is the same (i.e., if it's conceptually a
number, then make it extend the `Number` class, fuck your expectations).
